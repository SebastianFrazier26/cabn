# `@cabn/blog` implementation plan

Spec: `docs/superpowers/specs/2026-11-22-blog-design.md`. Branch: `feat/blog` off `main`.
Each task is test first, then code, then a commit. Gate per task:
`pnpm -F @cabn/blog test && pnpm -F @cabn/blog build && pnpm lint`.

## Tasks

1. **Scaffold `packages/blog`.** `package.json` (three exports, peer `react`, dev
   `react`/`react-dom`/types), `tsconfig.json` (as `packages/engine`), `LICENSE`, `README.md`.
   Build script: `tsc`, then copy `src/styles.css` and the font into `dist/`.
2. **`src/post.ts`.** `definePost`, `createBlog`, `BlogConfigError`, types.
   Tests: `tests/post.test.ts`.
3. **`src/route.ts`.** `parseBlogRoute`, `postHref`, `indexHref`. Tests: `tests/route.test.ts`.
4. **`src/markdown.ts`.** Parser extended from the engine's `markdownLite`: blockquote,
   image, rule, site-relative URLs. Tests: `tests/markdown.test.ts`.
5. **React components.** `src/Markdown.tsx`, `src/markdownPost.ts`, `src/Blog.tsx`
   (index, standard and bare post, not-found, link interception, document title),
   `src/styles.css`, font file plus its OFL licence. Tests: `tests/render.test.tsx`
   using `react-dom/server` streams so `Suspense` resolves.
6. **`src/build/`.** `escape.ts`, `feed.ts`, `sitemap.ts`, `page.ts`, `write.ts`,
   `scope.ts`, `index.ts`. Tests: `tests/build.test.ts`, `tests/scope.test.ts`.
7. **Guards.** `tests/importGraph.test.ts` (no engine or Phaser import anywhere; the
   build entry reaches no `.tsx` and no `react`). Confirm `pnpm check:packs` passes
   for the new package.
8. **Docs.** Package `README.md` (usage, host checklist, CSP notes), root `README.md`
   package table and "Releasing" list, `docs/ARCHITECTURE.md`, `CLAUDE.md`, root
   `CHANGELOG.md` entry dated 2026-11-22.
9. **Full gate.** `pnpm -r build && pnpm -r test && pnpm lint && pnpm check:packs && pnpm audit --audit-level=high`.
