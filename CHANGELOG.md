# Changelog

## 2026-09-20

- Repo rebooted as a TypeScript pnpm monorepo (M0 scaffold): workspaces for `packages/*`, `apps/*`, `tools/*`; TypeScript strict ESM, Biome, Vitest, Node 22, CI workflow.
- Rust prototype parked on the `rust-prototype` branch and removed from this branch.
- Icons moved to `assets/source/icons/`.
- Asset pipeline (M2): `@cabn/asset-pipeline` extracts a 28-color canonical palette from the five source icons (hand-rolled median-cut, no quantization library), attempts true-pixel sprite recovery (content-bbox crop, nearest-dominant downscale, palette-snap, gradient-tolerant flood-fill background removal), generates three hand-drawn placeholder sprites from a declarative pixel-map format, and writes a static `assets/generated/preview.html` for human review. Generated palette, recovered sprites, placeholders, and preview are committed; `manifest.json` lets future edits lock individual placeholders against regeneration.
- Asset pipeline art-direction pivot (M2 follow-up): the soft-rendered 1024² originals, not the crisp recovered sprites, are now the in-game art. `matte-originals.ts` reuses the same background-classification grid to cut a feathered alpha matte over the untouched original pixels (`assets/generated/originals/<name>.png` at 1024/512/256, plus 512/256 WebP). `soften.ts` is a new hand-rolled style pass (per-cell neighbor-luminance gradient shading, deterministic per-cell jitter and per-pixel grain, bloom bleed around bright cells, feathered silhouette edges) that turns a crisp pixel-map render back into the source art's soft-chunky look; calibrated by placing `soften(cabin_64)` next to the original `cabin.png` in the preview page. Palette gained 4 curated cool colors (steel gray, bone/moonlight white, pale ghost blue, cool shadow blue-gray) appended after the extracted 28, since the source icons have no cool neutrals. Ghost and character_idle placeholders redrawn (curvier wavy-tailed ghost in the new cool tones; Pokémon-BW-style big-head/short-body character); portal_arch kept as-is. `recover-sprites.ts` refactored to share `computeBackgroundGrid` with the new matte script instead of duplicating it.
