cabn — pixel-RPG UI mockup v2

Static style pass only. v1 (wood/parchment "storybook") was rejected — too textured, too muted. This is a reset: Stardew Valley / Pokémon B&W flat panels, a retro dialog pixel font, real item art in the hotbar, and a distinct particle effect per tool.

Backdrop: existing softened placeholder sprites (wizard_tower, character_idle, bonfire, ghost) over a brighter sky — same sprites as v1, new mood.

1. Tool hotbar — real item art, not emoji

Every slot now shows the actual tool: the opener reuses the existing key_256.webp (already in the right style), the other five are new pixel-map icons run through the same soften() pass as wizard_tower/character_idle so they land in the same soft-rendered family. Flat rounded slot, selected = gold ring + lift, no wood texture anywhere.

current: emoji-in-wood (v1, rejected)
