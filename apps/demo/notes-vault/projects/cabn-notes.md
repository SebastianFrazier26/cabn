# cabn: shelf hierarchy notes

Walking the M3 demo, cabins showing up *inside* a world never made sense — a
cabin should represent a whole converted world, not a place inside one.

## Redesign

1. **Shelf** — hub world, wizard tower centered, one cabin per world fanned
   around it. Each cabin gets a seeded color tint so worlds feel distinct but
   related.
2. **World** — spawn is a bonfire, not a cabin; cabinets for directories as
   before, tinted to match that world's cabin.
3. **Portals** — unchanged, except the file preview renders inside the arch
   opening now, not floating above it.
