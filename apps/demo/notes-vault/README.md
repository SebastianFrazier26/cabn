# notes-vault

A tiny personal notes vault — daily logs, recipes, and project scratchpads.
This is a fake demo project converted by cabn into a second, contrasting
walkable world: markdown-only, no code, to show that a converted world's
"feel" (biomes, file kinds) can look very different from `harvest-log` while
still living in the same shelf.

## Layout

- `index.md` — vault home / table of contents
- `daily/` — dated daily notes
- `recipes/` — cooking notes
- `projects/` — longer-running project notes
